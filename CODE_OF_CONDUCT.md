# Code of conduct

Be decent. Concretely:

- Critique code, designs and ideas — not people. No harassment, insults,
  or personal attacks.
- Assume good faith; newcomers' questions about an unfamiliar codebase
  are welcome, duplicated logic found in review is reported, not mocked.
- Keep discussions about the project: no politics, no spam, no
  advertising.
- When reporting bugs or pasting logs, respect that other readers may see
  them: redact real session content, file paths and identifiers you would
  not publish.

Maintainers may remove comments or block accounts that violate this.
Report conduct problems privately through GitHub (message a maintainer or
open a private security/contact report).

This project follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/) without
importing its full text.
