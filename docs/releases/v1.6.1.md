# Release v1.6.1 — reliability patch and public continuity proof

These are the release notes for the published **v1.6.1** tag, which carries
wheel and sdist assets. Install from the immutable tag shown under Upgrade.

This is a backward-compatible patch release. It does not change the Store or
Bridge schema, add a product telemetry path, or require any migration.

## Fixed

- A failed handoff no longer leaves stale lease/state behind. If a Continuation
  Bundle directory cannot be created, or the atomic bundle write fails,
  `handoff_thread()` releases the single-writer lease, clears the returned
  token, and records no pending attach. A later legal handoff no longer needs
  `thread unlock --steal`.

- `voyager demo --db PATH` stays isolated to the requested DB/environment. The
  demo subcommand now honours the global database override and seeds exactly
  the requested index instead of writing the default `demo.db` under the real
  home directory.

## Verification / Documentation

- A canonical verification matrix now distinguishes unit, integration,
  historical live, R16/R17 live, install-only, BLOCKED and NOT VERIFIED claims.
- A reproducible causal continuity demo is included under
  `examples/continuity-proof/`. It uses synthetic fixtures, a prewritten oracle
  and a deterministic verifier; no model, provider login, credential, real user
  data or GUI is involved.
- The README first screen now explains the local-history → WorkThread →
  continuation → next-agent flow and states the verification boundary directly.
- Small controlled experiments are included as reproducible evidence, not as
  statistical reliability claims.

## Compatibility

- Bridge schema remains `1`; no Bridge op was added or changed.
- No Store schema migration and no index migration are required. Indexes created
  by v1.6.0 remain readable by v1.6.1.
- Compatible with Plugin v1.4.0. No Plugin upgrade is required for this patch.
- Rollback to v1.6.0 is supported at the data/schema level; no new persistent
  field or migration is introduced.

## Upgrade

Install from the immutable release tag:

```sh
pipx install "voyager[all] @ git+https://github.com/HarryHeYu/sessionFlow.git@v1.6.1"
```

or:

```sh
python -m pip install "voyager[all] @ git+https://github.com/HarryHeYu/sessionFlow.git@v1.6.1"
```

There is no PyPI release for this version.

## Known limitations

- VS Code GUI / Extension Host / one-click switch E2E remains NOT VERIFIED in
  this environment.
- DSH model-driven autonomous tool selection on the seven-tool surface remains
  not live-verified.
- Native Resume is not verified here; see the safe manual procedure in
  `docs/native-resume-manual-verification.md`.
- `Evidence MATCH` means reference consistency, not that a quoted claim is true.
