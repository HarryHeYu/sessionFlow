# sessionFlow v1.0.0-rc2
**Unified AI Coding Agent Session Management**

Release candidate. Tag: `v1.0.0-rc2`.

This RC is about **first-time-user experience and open-source plumbing** —
no core-semantics changes: the bridge stays at schema v1, and the
verification, timeline and doctor models are untouched.

## Highlights

- **`voyager demo`** — explore sessionFlow with zero agents installed: a
  synthetic 4-agent / 1-WorkThread index (implement → review → debug →
  harden, one "authentication flow" working day) at `~/.voyager/demo.db`,
  separate from your real index. Every follow-up command the verb prints
  is regression-tested.
- **README with a real demo** — dual-path Quick Start (Fast Demo / Real
  Usage), product screenshots and a typed-terminal demo GIF, all
  generated from the synthetic index; a use-cases page (lost context /
  agent switching / engineering memory).
- **Release automation** — pushing a `v*` tag now runs the test suite on
  the tag tree and opens the GitHub Release (notes from
  `docs/releases/<tag>.md`, rc tags marked pre-release). The Windows CI
  matrix covers Python 3.10–3.13.
- **Contributor plumbing** — issue templates, PR template, a contributing
  guide documenting the O1–O6 architecture rules (single source of truth,
  evidence honesty, the safe-repair allowlist, versioned bridge), a
  security policy and a code of conduct.

## Install

```
git clone https://github.com/HarryHeYu/sessionFlow
cd sessionFlow
pip install -e ".[all]"
voyager demo            # 2-minute synthetic tour, no agents needed
voyager scan            # then index YOUR agents
```

PyPI packaging is prepared but not yet published.
