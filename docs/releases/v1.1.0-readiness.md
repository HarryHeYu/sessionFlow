## 2. Compatibility conclusion

**No breaking changes.** v1.1.0 is a correctness release.

| surface | status |
|---|---|
| Bridge `schema_version` | stays **1** (additive only) |
| The six `sessionflow_*` DSH tools | unchanged names and arguments |
| Core CLI commands | none removed or renamed |
| Index / store schema | additive migration only; no destructive rewrite |
| New JSON fields | additive; a client that ignores unknown keys needs no change |

Two **behavioural** changes an integrator should know about (both documented in
the release notes, neither a schema break):

1. `voyager continue` / `voyager switch` now exit **non-zero** when a repository
   has more than one active WorkThread and no `--thread` was given. Scripts that
   relied on "newest thread wins" must pass `--thread` explicitly.
2. Two bundle section headings were renamed (`## Latest assistant conclusion`,
   `## Other sessions' conclusions`). Anything matching the old strings — a
   parser, a saved prompt, a test — needs updating.
