**New Helper Functions Added:**
- `provider_context_budget(provider)` - Get declared startup budget in chars
- `provider_transport_limit(provider)` - Max bytes per hook payload
- `provider_truncation_behavior(provider)` - Truncation strategy
- `provider_supports_spill_pointer(provider)` - Spill pointer support
- `provider_auto_budget_target(provider)` - Map to preset name
- `resolve_provider_budget(provider, user_specified)` - Resolve actual token budget

**Budget Resolution Logic:**
1. User-specified budget overrides everything
2. Provider-specific `startup_context_budget` converted to tokens (chars/4)
3. Provider's `auto_budget_target` preset name used
4. Global default (AUTO_BUDGET_TOKENS = 20000) as fallback

#### 2. Updated `voyager/budget.py`

**New Function - `resolve_auto_budget(target: Optional[str]) -> int`:**
```python
def resolve_auto_budget(target: Optional[str]) -> int:
    """Resolve --budget auto using provider-aware defaults.

    Priority order:
    1. Provider-specific startup_context_budget converted to tokens
    2. Provider's auto_budget_target preset name
    3. Global default (20000 tokens)

    Returns token count (chars/4 estimate).
    """
```

**Updated Legacy Wrapper:**
