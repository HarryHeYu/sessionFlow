# Documentation index

Every tracked markdown file in this repository, what it is, who it is for, and
whether it is still maintained. This page classifies documents; it deliberately
does not restate them — follow the link for the content.

**Maintained** means the file is expected to change with the code. **Frozen**
means it is a record of a moment and is not edited again. A frozen file is not
wrong; it is history, and it should not be quoted as current state.

## Rules for adding a document

1. Put it in `docs/` unless it is one of the six root files (README, README.zh-CN,
   CHANGELOG, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY) or `AGENTS.md`.
2. Add it to this index in the same commit, with its kind and status.
3. If it is a record of one round rather than a description of the product, it
   belongs in `docs/releases/` (if it ships with a release) or `docs/archive/`.
   Do not add new phase reports to `docs/`.
4. Relative links are checked by `tests/test_docs.py`; run it before committing.

The index itself is checked by `tests/test_docs.py`: every markdown file under
`docs/` and at the root must be listed here, and every link here must resolve.
